# Krishnala Wallet — Chrome Extension

A lightweight KRIS wallet with **Krishnala testnet + mainnet pre-configured**. EVM-compatible.

## Install (Load unpacked)
1. Download this folder (or the .zip from https://krishnala.com/krishnala-wallet.zip).
2. Chrome → `chrome://extensions` → enable **Developer mode** (top right).
3. Click **Load unpacked** → select this folder.
4. Pin the Krishnala Wallet icon.

## Use
- **Create** a new wallet or **Import** a private key (0x...).
- Switch **Testnet / Mainnet** from the dropdown (both pre-configured).
- **Faucet** button → get 10 free KRIS (testnet).
- **Send** KRIS, **Add to MetaMask**, view balance.

Networks: Testnet chainId 713714 (rpc.krishnala.com) · Mainnet chainId 713715 (coming soon).
Built with ethers.js v6. Devnet — testnet KRIS has no monetary value.
